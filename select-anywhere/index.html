Android · version 0.1.0

Select text apps won’t let you select.

Select Anywhere gives you an on-demand selection layer for visible text in Android apps that do not provide usable native selection.

Preparing for Google Play
Select Anywhere
Selector active
Accessibility button → Select

Start only when you choose. No permanent floating trigger.

Local History

Selection on demand.

Outside an active selection session, taps, long presses and scrolling stay with the app you are using.

1
Start explicitly

Use Android’s Accessibility button or shortcut whenever you want to select something.

2
Choose precisely

Tap text, adjust START and END handles, and add multiple separate ranges when needed.

3
Copy, open, keep

Copy the selected text, open recognized URLs and keep confirmed selections in private local History.

Keep selecting while you scroll.

Scroll mode returns touch control to the source app so you can move naturally through the page, then Select recalibrates the visible screen without losing the ranges you already chose.

Private by design.

Visual recognition happens locally when needed, automatic backup is disabled, and confirmed History stays in private app storage. Select Anywhere 0.1.0 has no app-level network permission, no ads, no account and no backend.

The bundled Google ML Kit SDK may collect technical diagnostics and usage metrics for SDK analysis. OCR image/text content is not included in that telemetry. See the Privacy Policy for details.
Português (Brasil)

Selecione textos que outros apps não deixam selecionar.

O Select Anywhere cria uma camada de seleção sob demanda para textos visíveis em aplicativos Android que não oferecem seleção nativa utilizável.

1
Inicie explicitamente

Use o botão ou atalho de Acessibilidade do Android somente quando quiser selecionar algo.

2
Ajuste com precisão

Toque no texto, ajuste as alças INÍCIO e FIM e adicione múltiplos trechos quando necessário.

3
Copie, abra, guarde

Copie o texto, abra URLs reconhecidas e mantenha seleções confirmadas no Histórico privado e local.

A versão 0.1.0 não possui anúncio, conta, backend ou permissão de rede do app. Consulte a Política de Privacidade para detalhes sobre o processamento local e as métricas técnicas documentadas do Google ML Kit.
