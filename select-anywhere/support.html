Help with Select Anywhere

Select Anywhere is an on-demand Android text-selection utility. It uses an Accessibility Service that you enable manually and keeps confirmed selections in private local History on the device.

How to enable Select Anywhere

Open Select Anywhere, review the in-app Accessibility disclosure, choose Continue, then enable Select Anywhere in Android Accessibility settings. The Home screen will show when the selector is active.

How to start a selection

Open the app that contains the text you want. Use Android’s Accessibility button or configured Accessibility shortcut for Select Anywhere. A temporary capture layer appears only for that session. Tap a word, then adjust the START and END handles as needed.

How to select multiple parts

After selecting the first range, tap other visible text to add another explicit range. Confirmed ranges remain logically separate and are copied in the order you selected them.

How to keep selecting while scrolling

Choose Scroll to return touch control to the source app and use its native scrolling. When the desired text is visible, choose Select to recalibrate the current screen and continue selecting without automatically adding text that merely passed through the viewport.

Why some text may not be recognized

Android apps expose text in different ways. When usable character geometry is unavailable, Select Anywhere can analyze a temporary image of the current window locally on the device after you start a selection. The image is not saved. If a screen still cannot be selected accurately, make the text fully visible and try again.

How to copy or open a recognized link

Choose Copy to place the selected text on the Android clipboard. When a selected range contains a recognized URL, Open is available so Android can route that URL to an appropriate app or browser.

How to delete History

Open History to delete individual entries, or use Settings to clear the entire local History. Clearing Select Anywhere app data in Android Settings or uninstalling the app also removes the app’s private local data.

No permanent floating trigger

The shipping version of Select Anywhere does not keep a permanent floating “Aa” control over other apps. The selector starts only from Android’s Accessibility button or shortcut and temporary overlay windows exist only while a capture/selection session is active.

Privacy

Select Anywhere 0.1.0 does not request Android INTERNET or ACCESS_NETWORK_STATE permissions. OCR content and local History stay on the device. Google ML Kit may collect technical SDK diagnostics/usage metrics as described in the Privacy Policy.

Suporte · versão 0.1.0

Ajuda com o Select Anywhere

O Select Anywhere é uma ferramenta de seleção de texto sob demanda para Android. Ele usa um Serviço de Acessibilidade habilitado manualmente e mantém as seleções confirmadas em um Histórico privado e local no aparelho.

Como habilitar o Select Anywhere

Abra o Select Anywhere, leia o disclosure de Acessibilidade dentro do app, escolha Continuar e habilite o Select Anywhere nas Configurações de Acessibilidade do Android. A tela Início mostrará quando o seletor estiver ativo.

Como iniciar uma seleção

Abra o aplicativo que contém o texto desejado. Use o botão de Acessibilidade do Android ou o atalho de Acessibilidade configurado para o Select Anywhere. Uma camada temporária de captura aparece somente naquela sessão. Toque em uma palavra e ajuste as alças INÍCIO e FIM quando necessário.

Como selecionar múltiplos trechos

Depois de selecionar o primeiro trecho, toque em outro texto visível para adicionar uma nova seleção explícita. Os trechos permanecem logicamente separados e são copiados na ordem em que foram selecionados.

Como continuar selecionando durante a rolagem

Escolha Rolar para devolver o controle de toque ao aplicativo de origem e usar o scroll nativo dele. Quando o texto desejado estiver visível, escolha Selecionar para recalibrar a tela atual e continuar a seleção sem adicionar automaticamente o texto que apenas passou pela viewport.

Por que algum texto pode não ser reconhecido

Aplicativos Android expõem texto de formas diferentes. Quando a geometria dos caracteres não está disponível, o Select Anywhere pode analisar localmente uma imagem temporária da janela atual depois que você inicia uma seleção. A imagem não é salva. Se uma tela ainda não puder ser selecionada com precisão, deixe o texto totalmente visível e tente novamente.

Como copiar ou abrir um link reconhecido

Escolha Copiar para colocar o texto selecionado na área de transferência do Android. Quando uma seleção contém uma URL reconhecida, a ação Abrir fica disponível para que o Android encaminhe a URL a um aplicativo ou navegador apropriado.

Como apagar o Histórico

Abra Histórico para excluir entradas individualmente ou use Ajustes para limpar todo o Histórico local. Limpar os dados do Select Anywhere nas Configurações do Android ou desinstalar o app também remove os dados privados locais.

Sem gatilho flutuante permanente

A versão distribuída do Select Anywhere não mantém um controle “Aa” flutuante permanente sobre outros aplicativos. O seletor é iniciado apenas pelo botão ou atalho de Acessibilidade do Android, e as janelas temporárias existem somente durante uma sessão ativa de captura/seleção.

Privacidade

O Select Anywhere 0.1.0 não solicita as permissões Android INTERNET ou ACCESS_NETWORK_STATE. O conteúdo do OCR e o Histórico local permanecem no aparelho. O Google ML Kit pode coletar métricas técnicas de diagnóstico/uso do SDK, conforme detalhado na Política de Privacidade.
